# 问题链、图链与全文叙事

## 使用范围与优先级

本文件服务于增材制造高熵合金论文的提纲、主线重构、主副图规划与Discussion提升。
导师样文提供表达节奏和材料学叙事范式；Nature写作机制补充问题递进、证据选择和概念意义。
这里的Nature方法是写作经验归纳，不是Nature官方投稿规定，也不要求投Nature期刊。
本文件独立可用，不要求安装其他nature技能或调用外部服务。

- 尊重作者已确定的研究问题、当前实验事实和目标期刊要求。
- 在事实准确的前提下，优先采用导师的组织顺序、对照方式和句法习惯。
- 保留图号引导、相区细节、状态比较、定量结果与机制解释的连续推进。
- 将导师已发表的铸造、共晶与热处理结果用于学习写法；当前稿的材料状态由当前数据决定。
- 不为套用叙事而预设FCC/B2、L1₂、胞状亚结构、TWIP/TRIP或HDI必然出现。

## 1. 先写一句真实主张

从当前数据中选择最值得发表且可以成立的贡献。贡献可以是性能、机制、工艺窗口或失效边界。
一句话回答：做了什么改变、实际观察到什么、在哪些条件下有何意义。

> 在[合金与制造状态]中，[成分/工艺变量]对应[实测组织或缺陷变化]，在[测试条件]下实现[明确性能结果]；[关键证据]支持[限定的机制解释]。

这句话是工作模板，按论文实际贡献合并或删减，不强迫每篇同时具备全部槽位。
区分直接建立的发现、证据支持的解释和尚待检验的设想，再选择措辞。
对于充分观测和对照，不额外堆叠may、possibly、suggest等词。
对于未被直接区分的机制，保留与证据相称的限定，不能以文风自信代替验证。

| 工作项 | 填写内容 | 决策用途 |
|---|---|---|
| 中心发现 | 当前稿最重要的可证实结果 | 决定标题、摘要中心和主图 |
| 决定性比较 | 对照状态、方向、温度或工艺变量 | 说明发现如何成立 |
| 关键组织证据 | 相、尺度、分布、界面或缺陷的实际测量 | 连接工艺与性能 |
| 机制证据 | 变形观察、模型、载荷响应或其他诊断 | 确定解释强度 |
| 解释边界 | 哪些条件改变或限制结论 | 防止主张超出测试范围 |

此表放在内部工作笔记；交付正文时将它转化为连贯论证，不逐项写成检查报告。

## 2. 引言：痛点、未解问题与策略

先还原本文解决的具体困难，再安排背景和文献。不要默认所有论文都从强塑性倒置开篇。
AM论文可涉及可加工性、组织稳定性、各向异性、强塑匹配或缺陷敏感性，以当前课题为准。

建议的问题链：

1. **实际需求与具体瓶颈**：说明哪类材料、状态或应用受到什么限制，给出可信依据。
2. **已有解决路径**：按策略及其已经解释的内容组织文献，避免逐作者流水罗列。
3. **精确未知**：指出尚不能判断的来源、条件、机制或权衡，说明它为何影响设计。
4. **本文可检验策略**：解释所选成分、制造变量或后处理为何有望区分该问题。
5. **研究路线**：预告决定性比较和证据类别，保持与Results实际内容一致。

这些是段落功能，可合并为两长段，也可展开为三至五段，不设固定段数。
“尚无人研究本成分”不能单独承担科学问题；进一步指出该体系能够检验什么。
不把未做的实验、未覆盖的场景和假想审稿意见集中写在引言中。
若未测试的条件决定当前主张的含义，直接在该主张旁写清范围。

### 成分和工艺选择必须有理由

- 元素选择：把预期作用、文献/计算依据、可观测结果连起来；预期作用仍需当前证据检验。
- 工艺选择：指出改变的变量、对照保持的条件，以及它能回答的组织或性能问题。
- 后处理选择：说明目标是何种组织调整；不能在观察前宣布“消除偏析”或“形成最佳析出”。
- 工艺简化、成本或可制造性可以构成贡献，但需要相应比较，不能只用形容词自评。
- CALPHAD、经验相形成参数和热模拟提供设计依据，结论应与其假设和实验验证范围一致。

## 3. AM研究的可检验叙事链

使用“制造变量/热史 → 实测组织与缺陷 → 性能响应 → 变形或失效机制 → 设计含义”。
沿链条逐段确认已有证据；没有数据的连接保留为待验证问题，不填入行业常见结论。

| 链条环节 | 当前材料中寻找什么 | 写作边界 |
|---|---|---|
| 制造变量 | 制造路线、参数、扫描策略、构建方向、取样位置 | 只写实际使用并记录的条件 |
| 热史 | 实测温度、经说明的模拟或可验证的热影响比较 | 不由输入参数直接推定真实冷却速率 |
| 实测组织 | 相、晶粒、织构、析出、元素分配、亚结构 | 交代位置、方向、尺度与状态 |
| 缺陷 | 孔隙、裂纹、未熔合或其他确实观测到的特征 | 未见某缺陷不自动等于全体试样无缺陷 |
| 性能 | 当前测试的强度、伸长、硬化、疲劳等指标 | 明确温度、应变率、方向和指标定义 |
| 机制 | 当前变形/损伤证据与适用模型 | 静态图、模型吻合和推测分别表述 |
| 设计含义 | 在何条件下选择何变量能控制何结果 | 不扩展为所有AM–HEA的通用规律 |

LPBF、DED等路线按作者实际实验确定，不默认二者具有相同参数含义或组织演变。
相同体积能量密度不自动构成相同热史或等价工艺；是否足以支持比较需结合具体设计。
“as-built”“构建方向”“熔池”等术语应随当前稿事实采用，不为模仿样文改成铸态术语。
工艺造成组织改变、组织造成性能改变，是两项需要分别支撑的连接。
多个变量同步变化时，说明对照能区分到哪一层，避免把共同变化写成唯一原因。

## 4. 提纲与分章节写作

对于新全文或实质重构，先交付可核查的提纲、数据对应和图链，由作者确认后写正文。
提纲确认时核对中心主张、样品状态、决定性比较、章节问题和尚缺信息，不重复索取已知资料。
材料不足的段落标明缺失内容；继续完成不依赖该缺口的部分。
已有作者确认的提纲和判断跨轮沿用，只有实质变化才重新对齐受影响部分。

| 章节 | 需要完成的任务 | 可采用的导师节奏 |
|---|---|---|
| Abstract | 压缩策略、组织、关键性能、机制和意义 | 直接给研究对象与结果，背景按需要配置 |
| Introduction | 从问题和文献依据导向可检验策略 | 元素/工艺职责明确，性能与机制文献成对出现 |
| Methods | 让读者复现实际样品与测试 | 操作、条件、取样、统计和计算来源具体 |
| Results | 依次建立当前稿的事实和比较 | 图号→观察细节→状态比较/定量→局部解释 |
| Discussion | 综合证据解释构效关系 | 强化、变形和损伤互证，再提炼设计条件 |
| Conclusions | 保留最需要记住的发现和适用范围 | 用准确结果收束，不加入新机制或新数据 |

Results与Discussion可分开或合并，遵循目标期刊及作者提纲。
组织表征、力学性能和变形后表征可按问题安排；不强制每篇先XRD再SEM再EBSD再TEM。
实际写作可先稳定Results和Methods，再组织Discussion、Introduction，最后压缩Abstract与标题。
若作者指定从某章开始，就在已核对事实的范围内完成该章，不以写作顺序阻碍交付。
局部润色只处理所给段落、必要相邻关系和相关一致性，不重启全文提纲或重新定义贡献。

### 摘要的压缩方法

保留“必要背景/问题 → 设计策略 → 组织变化 → 关键性能 → 有依据的机制 → 设计意义”。
导师样文的句数、开篇方式和功能比例有变化，此链不等于固定六句或固定百分比。
只保留能改变读者判断的数值；材料类性能主张通常需要清楚的指标、条件和比较对象。
不能把拉伸/压缩、均匀伸长/断后伸长、强塑性/断裂韧性互换以压缩文字。
最后一句说明结果建立了什么理解或设计条件，避免泛泛宣称“具有巨大应用前景”。

## 5. 主图与子图按证据职责编排

每幅图先用一句带动词的判断说明它要建立什么，再决定放哪些面板。
一幅图通常围绕一个主要问题，可含多个为此服务的子发现，不设固定面板数。
主图顺序形成问题递进，而非实验完成顺序或仪器清单。

| 面板角色 | 应回答的问题 | AM稿中的可能形式，须有真实数据 |
|---|---|---|
| 材料/对照设置 | 比较对象和方向是什么？ | 工艺、取样或测试方向示意 |
| 代表性观察 | 特征具体长什么样？ | 组织、缺陷或变形结构图 |
| 定量证据 | 变化有多大、分布怎样？ | 尺寸、相分数、曲线、统计分布 |
| 必要对照 | 哪个比较支撑此结论？ | 工艺状态、方向或处理条件对照 |
| 正交验证 | 另一种证据能否确认解释？ | 衍射/成分/形貌相互补充 |
| 机制诊断 | 何种解释更受支持？ | 变形中断、相级响应或适用模型 |
| 边界/反证 | 结论在哪些条件改变？ | 不利状态、失效模式或负结果 |

为每幅图在工作笔记填写：

```text
科学问题：
图级主张：
决定性比较：
面板顺序及各自证据职责：
每个面板不可替代的推断：
哪些结果会改变此主张：
正文、图注、Methods与SI分别承载什么：
```

决定性证据获得清楚的视觉位置；代表图与量化相连，比较面板的颜色、尺度和样品标识一致。
构建方向、截面位置、放大区域和变形状态要能对应，不把不同来源图像排成虚假的时间序列。
删除某面板若不损失独有信息，优先合并或移到SI；不要只因另一个指标可画就新增主图。
若相鉴定、关键对照或不利结果改变中心解释，应在正文中可见，不能因叙事不顺移走。

- **正文**：说明发现、决定性证据和对中心问题的意义。
- **图注**：说明对象、状态、面板对应、符号、尺度及必要统计，保持离开正文仍可读。
- **Methods/源数据**：保存可复现步骤、统计定义、计算输入和数据来源。
- **SI**：容纳非中心的扩展表征、重复验证、细节和更完整的分析。

保留导师常见的`Fig. n. 总述. (a)… (b)…`节奏，具体标号、图注长度和格式服从目标期刊。
不把Nature的`Fig. N |`、图数或图注字数当成所有材料学期刊要求。

## 6. Discussion：从结果走向可用的理解

用一个准确判断恢复中心发现，随后解释多项结果合在一起允许得出什么。
避免把性能曲线、所有图号和全部数值再讲一遍。

1. 连接工艺/成分改变与实测组织，不跳过中间证据。
2. 结合相、界面、缺陷和尺度解释强度；只在需要且输入可靠时展开定量模型。
3. 结合硬化、变形结构、应变分配和损伤解释延性或失效，防止只解释初始屈服。
4. 与最相关工作比较：明确支持、扩展、修正或冲突在哪里。
5. 提炼有限的设计规则，说明控制变量、目标组织、性能收益及其适用条件。
6. 指出仍改变解释的未知，并给出能区分竞争机制的下一问题。

模型细节按需查阅[strengthening-models.md](strengthening-models.md)。
计算与实验接近可以支持一致性；是否区分竞争机制，还取决于独立组织和变形证据。
不把模型残差统一归因于“其他强化”，也不在无参数时补一套看似精确的贡献比例。
没有断裂韧度等相应测试，结论应落在实测强度、伸长或损伤行为，不扩大为韧性已提高。
局限应说清影响哪项解释、哪些范围仍成立；不以笼统自我否定收尾。

## 7. 去防御性写作：先稳定主张，再清理包装

检查句子是否提供证据、限定范围、澄清概念或推进推理；没有这些作用的辩解可删。
段首优先陈述本段发现或问题。重复的免责、先道歉再报告、向想象审稿人解释可直接改写。
“不是X而是Y”、rather than、however、although只在有实际概念区别或转折时保留。
用具体状态和适用范围替代反复说明本文不研究什么；必要排除条件仍须完整表达。
保留导师有依据的积极评价和归因，包括excellent、superior、is mainly attributed to等表达。
评价紧邻数据与比较范围；机制措辞依照证据，不把全部归因统一弱化，也不自动升级推测。
删去无信息的“遗憾、仅仅、效果有限”；提高与降低的指标、负结果及必要比较继续如实报告。
真实不确定性使用适配的限定，删叠加和重复，不因“去防御”抹去科学含义。
未做实验造成的机制缺口应转成具体推断边界，不替作者编造实验、原因或合理权衡。
内部核查记录与作者沟通可保留问题清单；论文正文用事实和推理表达，不搬入审核口吻。

## 8. 导师样例与AM迁移的区别

以下“样例观察”来自用户提供论文；“AM迁移”是写作建议，不是八篇已证明的AM结论。

| 样例观察及定位 | 可以学习的论证动作 | AM迁移建议 |
|---|---|---|
| P03：双重异质结构论文，Results/Discussion，Figs. 2–9 | 处理后组织→性能对照→LUR响应→变形后缺陷，证据角色递进 | 若当前稿讨论异质变形，以实际空间/相级差异和载荷证据连接，不预设存在HDI定量结果 |
| P04：L1₂析出论文，Results与Discussion，Figs. 3–17 | 前后状态配对；晶粒粗化与强度提高并存，进一步检验析出贡献 | AM后处理稿应同时保留晶粒、缺陷与析出演化，不能只选有利于细晶解释的结果 |
| P08：Co基双相论文，Figs. 7–12 | 相分数、形貌、相级力学与整体压缩性能一起讨论 | 当AM状态出现相似的指标反转，围绕当前证据追问来源，不复制该铸造体系的机制答案 |

P03 DOI：`10.1016/j.matchar.2025.114812`；P04 DOI：`10.1016/j.msea.2026.150599`。
P08 DOI：`10.1016/j.matchar.2024.114572`。P编号仅用于追溯这些样例，不要求作者在新论文沿用编号。

## 9. 内部自检，按任务范围调用

按原创性、方法严谨性、证据充分性、论证连贯性、写作质量五维检查，不设分数总和。
每个实际问题记录位置、受影响主张、证据和最小补救；不制造问题数量或泛泛索要新实验。
材料学重点核对：工艺/取样/方向与测试可复现；相鉴定和尺度统计恰当；曲线指标与误差准确。
另核对：模型参数/单位/重复计数；晶体学和缺陷解释；文献比较条件；摘要与正文主张一致。
不以误差条重叠替代统计判断，不以KAM直接替代总位错密度，不从断后静态图补全过程。
先修数字、术语和证据连接，再调句法。局部修改只复核受影响内容，发现更广问题再扩大。
完成正文时只附作者确需处理的缺口或关键改动，不自动追加整份审稿检查表。
